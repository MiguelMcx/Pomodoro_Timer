# Pomodoro Timer

Temporizador Pomodoro para Android, hecho con **Kotlin** y **Jetpack Compose**. Alterna sesiones de trabajo y descansos para ayudarte a mantener la concentración.

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat-square&logo=kotlin&logoColor=white)
![Android](https://img.shields.io/badge/Android-3DDC84?style=flat-square&logo=android&logoColor=white)
![Jetpack Compose](https://img.shields.io/badge/Jetpack_Compose-4285F4?style=flat-square&logo=jetpackcompose&logoColor=white)

## Requisitos

- Android Studio (versión reciente)
- Un dispositivo o emulador con Android 15 (API 35) o superior

## Cómo ejecutarlo

```bash
git clone https://github.com/MiguelMcx/Pomodoro_Timer.git
```

Abre la carpeta en Android Studio, espera a que termine la sincronización de Gradle y pulsa **Run**.
